# admin/ — submission and decision material (committed; visible to this paper's co-authors)

What belongs here: submission packages, cover letters, title pages, editor decision
letters, referee reports, response-letter PDFs, dated audits — anything about THIS
paper that its co-authors may see. Name files `yyyymmdd-<what>.pdf/.md`.

What never belongs here:
- strategic-voice advisor notes → `CLAUDE.local.md` or a gitignored `yyyymmdd-*.md` at the repo root;
- anything about another student or another paper → that project's folder;
- grades, evaluations, recommendation letters → `02-HWTeng/03-lab/`, never any repo.
