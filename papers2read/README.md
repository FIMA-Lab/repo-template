# papers2read

PDFs are named by their BibTeX key in Google Scholar style, all lower case:
first-author surname + year of the cited version + first non-stopword of the title,
e.g. `lee2008jumps.pdf`, `clark2019does.pdf` ("What does BERT look at?" skips "what").
Use the same key in `overleaf/ref.bib`, so the file name and `\cite{...}` always match.

One line per paper: key — authors (year). Title. Venue. DOI.
